**English** · Download **`ChestCounter.exe`** below and run it. Nothing to install. Already using it? The counter offers the update on its home tab (**Install** button). Your history and settings are kept.

> **Turn on replays in Fortnite first**: *Settings → Game → Replays → Record Replays: On*. The tool only reads these replay files: no game modification, no access to the game's memory.

Flaimeur's version, based on [LED-N's ChestCounter](https://github.com/LED-N/Fortnite-ChestCounter) 1.5.1 (MIT license).

**What's new in 1.6.0**
- **New look**: dark background, plain cards and a gold accent, like the old report. No more parchment or pirate font, in the window and in the report
- **New logo**: a gold chest, for the exe, the window and the report
- **Updates** now come from this repository (Flaimeur/Fortnite-ChestCounter). The treasure hunt data (weeks, odds, Treasure Hours) still arrives by itself from LED-N's repository

Windows may show *"Windows protected your PC"* (unsigned exe): *More info → Run anyway*.
